Crypto Investment Analyzer
========================================

Files included:
- Config.java
- MarketData.java
- InvestmentAdvice.java
- ApiClient.java
- JsonParser.java
- ScoringEngine.java
- CryptoAnalyzer.java
- crypto_analysis_output.txt (sample output)
- REPORT.pdf (one-page report)

To compile:
  javac -d . *.java

To run:
  java -cp . com.crypto.analyzer.CryptoAnalyzer

Sample output is in crypto_analysis_output.txt
